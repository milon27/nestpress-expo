# Nestpress Expo project 👋

This is an [Expo](https://expo.dev) project architect with nestpress style.

## Get started in dev

1. Install dependencies

    ```bash
    yarn install
    ```

2. Start the app

    ```bash
    yarn start
    ```

## Code style

-   `/app` folder used for routing only
-   `/views/screens` folder use for all screen, these screen will be render on the router
-   rest of the code is same as [Nestpress Frontend](https://github.com/milon27/nestpress-frontend)
